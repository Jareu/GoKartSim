🔧 QUICK CONFIGURATION
═══════════════════════════════════════════════════════════════════════════════

Basic Setup (in simple_sim.py, line ~1546):

    engine_audio = EngineAudio(
        audio_file="sound/engine.wav",    # Audio file path
        idle_rpm=engine_cfg.rpm_idle,     # Idle RPM (default: 1200)
        redline_rpm=engine_cfg.rpm_redline, # Redline RPM (default: 6500)
        min_pitch=0.5,                    # Deep pitch at idle
        max_pitch=2.0,                    # High pitch at redline
    )

Pitch Range Presets:
• Realistic:  min_pitch=0.7,  max_pitch=1.4  (subtle changes)
• Normal:     min_pitch=0.5,  max_pitch=2.0  (default)
• Extreme:    min_pitch=0.3,  max_pitch=2.5  (dramatic changes)

🧵 THREAD ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════════

                    Main Thread                  Audio Thread
                 (Game Loop 120 FPS)          (Audio Callback 48 kHz)
                         │                              │
              car.update()│                              │
                         ├─ omega_e updated             │
                         │                              │
         engine_audio.set_rpm(rpm)                      │
                         ├─ Acquire Lock              │
                         ├─ Calculate pitch           │
                         ├─ Update self.speed ────────┼──┐
                         └─ Release Lock              │  │
                                                       │  │
                     pygame.display.flip()            │  │
                                                  callback()│
                                                  ├─ Acquire Lock ◀ Waiting
                                                  ├─ Read self.speed
                                                  ├─ Interpolate
                                                  └─ Release Lock
                                                       │
                                                 Audio Output ──→ 🔊

Thread safety achieved with threading.Lock - no race conditions!

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: No audio output

Check 1: Audio file exists
  $ ls -la sound/engine.wav

Check 2: Dependencies installed
  $ python -c "import sounddevice; import soundfile; print('OK')"

Check 3: System volume is turned up
  • Check system volume (not muted)
  • Check if audio device is selected

Check 4: Verify import works
  $ python -c "from gokart_sim.audio import EngineAudio; print('OK')"


Issue: Audio crackling/stuttering

Solution: Increase audio buffer size in gokart_sim/audio.py (line ~215)
  blocksize=4096  # Increase from default 2048


Issue: Audio lags behind engine

Solution: Ensure set_rpm() called after car.update() in simple_sim.py
  car.update(...)
  current_rpm = car.engine.omega_e * 60.0 / (2 * math.pi)
  engine_audio.set_rpm(current_rpm)  # ← Must be after update


Issue: High CPU usage

Solution: Check system load or lower blocksize
